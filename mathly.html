Introduction

The heart of MathLua (aka Lua + Mathly) is Mathly, a Lua module which turns Lua into a tiny, free, but powerful MATLAB. It provides a group of commonly used MATLAB functions and features, including linspace, zeros, rand, save, plot, plot3d, and convenient matrix operations as well. If there is anything many love the most about MATLAB, these tools are. They make coding and testing a thought/algorithm much easier and faster than working in most other programming languages. Besides, animate and manipulate allow easy and cool animation of 2D curves.

MathLua uses Plotly JavaScript graphing library to plot graphs. Therefore, graphs and animations are displayed in an internet browser, which makes it easy to share your animations with others.

The entire MathLua tool, including Lua interpreter, Mathly, and Plotly, is less than 5 MB, while providing enough features for instructors and college students to implement numerical algorithms. Because it is super lightweight and fast as well, it can run fast even on old and slow devices like Microsoft Surface Pro 4 (Intel Core i5-6300U with 8 GB RAM). In contrast to it, MATLAB needs a few GB of storage space. In addition, it takes about 22 seconds to start MATLAB R2024b on a new high-end Intel Core i9-14900HX laptop with 56 GB RAM. Thus, it can hardly be installed on slow or pretty old computers and run smoothly.

MathLua is especially a good choice for instructors of linear algebra and numerical computing. It takes no time to start Lua with Mathly loaded. While developing code and doing computation in a lecture, they can simply focus on delivery of course contents and never need to worry if their computers work too slowly. Moreover, Lua is so simple and so natural a language that students without programming skills can understand most of Lua code.

Which version of Lua is supported? Is there any IDE for MathLua?

MathLua is developed in Lua 5.4.6. It works with Lua 5.5.0 and might work with previous versions. You may download Lua source code in https://lua.org/ and compile it yourself or simply download prebuilt binary commands for Microsoft Windows in, say, https://www.nuget.org/packages/lua/. Another way to get prebuilt Lua is to download ZeroBrane Studio, a lightweight Lua IDE for various platforms. It may come with multiple versions of Lua.

Two text editors, CudaText and Lite XL, are each a very good "IDE" for MathLua. You may download the editors with MathLua included and integrated on GitHub.

By the way, Mozilla Firefox is the default internet browser. If you use a different browser, you need to edit the file browser-setting.lua coming with MathLua. See comments in the very file.

MathLua objects and Lua tables

  1. A MathLua table is a simple Lua table registered as a MathLua object. E.g., x = tt{1, 2, 3} is such a table. It has the same structure as an ordinary Lua table y = {1, 2, 3}. The difference is that we can apply "vectorization" operations and matrix operations on x instead of y. For instance, 2 * x - 1 gives a new MathLua table, {1, 3, 5}. Here, x[i] gives the i-th element in the table.

  2. A MathLua row vector is actually a 1xn matrix. E.g., x = rr{1, 2, 3} is a MathLua row vector. It is stored as {{1, 2, 3}}. To access 2, we must use x[1][2]. Similarly, a column vector y = cc{1, 2, 3} is a 3x1 matrix stored in the format {{1}, {2}, {3}}. We use y[2][1] to access 2. Indeed, x[1][2] or y[2][1] is quite strange and inconvenient, which is why the results of most operations on these row/column vectors and matrices and many MathLua functions are MathLua tables.

  3. MathLua tables and matrices may simply be called MathLua objects. MathLua objects and Lua tables can appear in same math expressions. MathLua automatically converts Lua tables and MathLua tables into MathLua matrices of proper dimensions to complete the evaluation of the expressions. We may use MathLua functions such as mathly, cc, rr, tt, and ^T to replace the automatic conversion by MathLua.

  4. In a vector/matrix operation involving Lua tables which are not MathLua objects, there must be at least one MathLua object to activate the operation. For example, tt{1, 2} + {3, 4}, {1, 2} + tt{3, 4}, ({1, 2} * tt{3, 4} + {5, 6}) * 7 - {8, 9}, and tt{1, 2} * {3, 4} + ({5, 6} - tt{8, 9}) * 7.
mathly = require('mathly')

a = mathly{{1, 2, 3}, {2, 3, 4}}
b = mathly{{1}, {2}, {3}} -- or simply b = cc{1, 2, 3}
A = mathly(10, 10)        -- or rand(10, 10)
B = mathly(1, 10)         -- or rand(1, 10), a MathLua table

inv(A) * B                -- B is interpreted as a 10x1 matrix
inv(A) * B^T              -- B^T can be cc(B). We control the conversion
a * {5, 6, 7}             -- Lua table {5, 6, 7} can be cc{5, 6, 7}
{5, 6} * a                -- Lua table {5, 6} can be rr{5, 6}

x = tt{2, 3, 4} + {5, 6, 7}
x ^ 3 - 5 * x ^ 2 + 4 *x - 1

A = randi({50, 100}, 3)
B = randi({0, 10}, 3)
C = 3 * A - 4 * B + 5
D = A .. B .. C           -- concatenate matrices A, B, and C horizontally
disp(D)
E = A .. cc{1, 2, 3}
disp(E)

-- matrix/table "division" is elementwise, provided for convenience only
x = {1, 2, 3, 4, 5}
rr(x) / 10
1 / (2 * rr(x) + 1)
x / cc(cos(x))

A = mathly{{1, 2}, {3, 4}}
1 / A
{{2, 3}, {4, 5}} / A

-- elementary row operations
A = randi({-100, 100}, 5, 7)
A[3] = A[3] * 2         -- rowi := rowi * scaler
A[2] = A[2] - A[1] * 2  -- rowj := rowj - rowi * scaler
A[1], A[3] = A[3], A[1] -- interchange 2 rows

-- plot multiple functions on a single figure
x = linspace(0, pi, 100)
y = 5 * x * cos(x ^ 2) - 1
plot(x, y, '-r', x, -3 * x ^ 2 + 2 * x + 3, '--b')

Basic mathematical functions and elementwise operations

✓   Basic mathematical functions

Basic math functions are each now able to work elementwisely on Lua tables, including MathLua objects. They are abs, acos, acot, asin, atan, ceil, cos, cot, csc, deg, exp, floor, log, log10, rad, random, sec, sin, sqrt, and tan. They evaluate a function at every number in a table and keep the structure of the table.

require('mathly')

A = randi(100, 5, 6)
disp(cos(A))

x = {-10, 12, -3, {4, -5, {6}}}
disp(abs(x))
-- {10, 12, 3, {4, 5, {6}}}
format 'short'
disp(log10(abs(x)))
-- {1.0000, 1.0792, 0.4771, {0.6021, 0.6990, {0.7782}}}

deg{pi/2, pi}
-- 90.0000 180.0000
rad(180)
-- 3.1415926535897931

✓   With each of these functions, should we use, say, sin(x) or math.sin(x)? You can always use sin(x). However, if you know x is a number, you may call math.sin(x) to get a little improvement in time performance.

✓   Elementwise operations through map

We can do elementwise operations, simple or complicated, through map.

require('mathly')

A = randi(100, 5, 7)
B = randi(100, 5, 7)
C = map('@(x, y) x * y', A, B) -- A .* B; -- A, B can be any type of tables with the same structure
disp(C)
C = map('@(x, y) x / y', A, B) -- A ./ B
disp(C)
disp(map('@(x) x ^ 2', A))     -- A .^ 2

D = map('@(x, y, z) qq(iseven(x), x - y + 3 * z, x + y * y)', A, B, C)
disp(D)

E = map('@(x, y) {x, y}', {1, 2, {3, {4}, 5}}, {'a', 'b', {'c', {'d'}, 'e'}})
disp(E)
-- {{1, "a"}, {2, "b"}, {{3, "c"}, {{4, "d"}}, {5, "e"}}}

disp(sin{1, 2, {3, {4}, 5}})

✓   Functions div and mod can simply be the names of Lua operators // and %, respectively. They make Lua code more understandable to people who are new to Lua. They follow the definition: if d > 0, r = mod(a, d) is the remainder of a divided by d with 0 ≤ r < d while div(a, d) gives the quotient. For more usage, see div and mod.

✓   Like mod, div, and operators +, -, * and /, operator ^ supports elementwise operations. If n is a table, a non-integer or a negative number, or A is a row/column vector (simply, undefined mathematically), A ^ n is elementwise.

mathly = require('mathly')

x = 2 ^ tt{1, 3, 5} -- {2^1, 2^3, 2^5}
disp(x)
-- 2.0000  8.0000 32.0000

x = tt{1, 3, 5} ^ 2 -- {1^2, 3^2, 5^2}
disp(x)
-- 1.0000  9.0000 25.0000

{3, 4, 5} ^ tt{0, 1, 2} -- {3^0, 4^1, 5^2}
-- 1.0000  4.0000 25.0000

A = mathly{{1, 2}, {3, 4}}
-- 1 2
-- 3 4
2 ^ A
-- 2.0000  4.0000
-- 8.0000 16.0000
A ^ {{2, -2}, {3, 1}}
--  1.0000  0.2500
-- 27.0000  4.0000

A ^ 3   -- A*A*A, power of matrix
-- 37  54
-- 81 118
A ^ 3.0 -- elementwise
--  1.0000  8.0000
-- 27.0000 64.0000
A ^ -1  -- elementwise
-- 1.0000 0.5000
-- 0.3333 0.2500

A ^ 0 -- eye(size(A))
-- 1 0
-- 0 1
A ^ 0.0
-- 1.0000 1.0000
-- 1.0000 1.0000

-- use map(...) to implement elementwise operations on non-MathLua tables
a = {1, w = 3, {4, {-5}}} -- a^2
disp(map('@(x) x^2', a)) -- {1^2, w = 3^2, {4^2, {(-5)^2}}}
-- {1.0000, {16.0000, {25.0000}}, w = 9.0000}

-- 2 ^ {1, w = 3, {4, {-5}}}
disp(map('@(x) 2^x', a)) -- {2^1, w = 2^3, {2^4, {2^(-5)}}}
-- {2.0000, {16.0000, {0.0312}}, w = 8.0000}

b = {2, w = 0, {3, {1}}} -- a^b
disp(map('@(x, y) x^y', a, b)) -- {1^2, w = 3^0, {4^3, {(-5)^1}}}
-- {1.0000, {64.0000, {-5.0000}}, w = 1.0000}

•   all(x, f), any(x, f)

  1. all(x, f): Test if f(x) is true for every number in x.

    If x is a table or a row/column vector, returns 1 if all elements of the table make f(x) true.

•   cc, rr, tt

A matrix operation may be applied to an ordinary table. It takes the table as a row or column vector according to the very context. If you want full control, you can use cc or rr to tell MathLua whether the table is a column or row vector.

Each function has an argument, irange, a range of index values. See copy.

cc(x, i, irange) Convert table x into a column vector or return specified columns of a MathLua matrix...
rr(x, i, irange) Convert table x into a row vector or return specified rows of a MathLua matrix...
tt(x, irange) Convert x to an ordinary table and return a slice of it.

✓   Why not cc, rr, and tt? It is because they can easily be used as names of variables or so.

✓   rr and cc have same usage, except that one is about row(s) and the other is about column(s). Take rr as an example:

rr(x)Convert x to a row vector.
rr(A, i)Return a row vector which is the i-th row of matrix A.
rr(A, i, {start, stop, step})Return a row vector which is a slice of the i-th row of matrix A starting from column start to stop increasing by step.
rr(A, {i1, i2, ...})Return a matrix consisting of rows i1, i2, ..., of A.
rr(A, {i1, i2, ...}, {start, stop, step})Return a matrix consisting of rows i1, i2, ..., of A. Each row is a slice of the very row of A starting from column start to stop increasing by step

Notes:

  1. i, i1, i2, ..., start, and stop can be negative integers. E.g., if i = -1, it refers to the last row/column; if i = -2, it denotes the row/column right before the last row/column; ... submatrix and subtable allow this usage, too.

  2. The default value of step depends on the values of start and stop. If start ≤ stop, it is 1; otherwise, it is -1. And the default value of stop is -1, i.e., the index of the last entry of a row/column.

  3. cc(A) and rr(A) each flatten a matrix rowwisely, but tt(A) does it columnwisely.

•   copy(A, rowrange, columnrange, B, rowrange1, columnrange1)

Make a deep copy of matrix A - copy(A, rowrange, columnrange)
Make a deep copy of table A - copy(A, irange)
 
Copy to matrix A from matrix B - copy(A, rowrange, columnrange, B, rowrange1, columnrange1)

It is a general tool for making a deep copy of x. If x is a table, rowrange can be specified. If it is further a (MathLua) matrix, columnrange can be specified.

Arguments rowrange* and columnrange* are ranges of index values described below.

✓   A range of index values is denoted in the format of {start, stop[, step]}, where start and stop are the starting and terminal index values, respectively, with index increasing by step. Both can be negative with -1 referring to the last element (row/column) of a table (or matrix), -2 the next last element, and so on. step defaults to 1 if start is less than stop; otherwise, it defaults to -1. Especially, '*' as a shortcut can be used to denote the whole range of index values.

For example, given that x = {1, 2, 3, 4, 5, 6, 7}, {1, -1} is the same as '*', {1, -1, 1}, or {1, 7, 1}, and {-1, 1} is the same as {7, 1} or {7, 1, -1}.

•   integral2(f, {g1, g2}, {a, b})

For better accuracy, a large interval in both the x and y directions is divided evenly into multiple subintervals, and Gauss quadrature method is applied to each one. See integral.

✓  The order of the arguments of the integrand, f(x,y), from right to left, defines the order of integration. By rearranging the order of these arguments, we can handle double integrals over all x and y-simple regions.

✓  Especially, with polar coordinates, the integrand will be like f(θ,r) due to ∫∫f(θ,r)drdθ.

require('mathly')

disp(integral2('@(x, y) x + y', {0, 1}, {0, 1}))

disp(integral2('@(x, y) x * y', {'@(x) x', '@(x) 2*x'}, {0, 1}))
-- 0.3750000000000 (exact: 3/8 = 0.375)
disp(integral2('@(x, y) x + 2*y', {'@(x) 2 * x^2', '@(x) 1 + x^2'}, {-1, 1}))
-- 2.1333333333333 (exact: 32/15 = 2.1333333333333)

-- ∫∫f(y,x)dxdy: here, z = 2x + 3y should be '@(y, x) 2*x + y' instead of '@(x, y) 2*x + y'
disp(integral2('@(y, x) x^2 + y^2', {'@(y) 0.5 * y', '@(y) sqrt(y)'}, {0, 4}))
-- 6.1714280951756 (exact: 216/35 = 6.1714285714286)

-- with polar coordinates: ∫∫f(θ,r)drdθ
disp(integral2('@(theta, r) r^3', {0, '@(theta) 2*cos(theta)'}, {-pi/2, pi/2}))

•   map(f, tbl1, tbl2, ...)

Apply recursively function f to each group of corresponding atomic elements in tables, tbl1, tbl2, ..., and return the result.

✓   tbl1, tbl2, ... do not have to be tables. If at least one is a table, it triggers elimentwise operations. The first such table from left to right, X, determines the structure of the final result. See also: ff, Shortcut for defining an anonymous function.

-- {1, 4, 9, 16, 25, 36, 49, 64, 81, 100}

disp(map('@(x, y) x + y', a, b), '') -- or a + b
-- {2, 6, 12, 20, 30, 42, 56, 72, 90, 110}

disp(map(f, {1, 2, {3, 4, {5, 6, {7}}}}), '')
-- {1, 4, {9, 16, {25, 36, {49}}}}

-- 1   4   9
-- 9  16  25
-- 1   4   0

Shortcut for defining an anonymous function

Whenever a function (or function handle) is passed to another function as an argument, if it can be expressed by an algebraic or logical expression, it can be defined in a string of the the format, '@(variabls) expression'. It is a MATLAB-style anonymous function but in a string.

Many MathLua functions accept such an argument, including all, any, apply, map, match, plot, plot3d, parametriccurve2d, plotparametriccurve3d, polarcurve, plotparametricsurface, plotsphericalsurface, sort, etc. The function, ff(str), is called to convert an anonymous function in a string to a Lua function.

Note: @(...) requires at least one argument.

✓   See ff.

require('mathly')

clear()
disp(all({1, 2, 3, {4, {5}}}, '@(x) x > 0'))      -- 1
disp(any({1, 2, 3, {4, {5}}}, '@(x) x % 3 == 0')) -- 1
disp(apply('@(x, y, z) x + y + z', {1, 2, 3}))    -- 6
disp(map('@(x) x*x', {1, 2, 3, {4, {5}}}))        -- {1, 4, 9, {16, {25}}}
plot(sin, '@(x) 0.5*x^2 - 5', '-r', '@(t) cos(t)*t-3', '--g', {xrange={-pi, pi}})
plot(parametriccurve2d({'@(t) t', '@(t) t^2'}))   -- x(t) = t, y(t) = t^2, i.e., y = x^2
plot(polarcurve('@(t) cos(t) + 2*t'))             -- r(θ) = cos(θ) + 2*θ
plot3d('@(x, y) x^2 - y^2')                       -- f(x, y) = x^2 - y^2
plotparametriccurve3d({'@(t) 10*sin(t)', '@(t) t^2 - 10*t + 2', '@(t) t^3'})           -- x(t) = 10 * sin(t), ...
plotparametricsurface({'@(u, v) sin(u)*v', '@(u, v) cos(u)*v - 2', '@(u, v) u + v'}) -- x(u, v) = sin(u)*v, ...
plotsphericalsurface('@(t, p) sin(t) + 5*p')    -- ρ(θ, φ) = sin(θ) + 5*φ
disp(sort({2, 5, 1, -3}, '@(x, y) x > y'))

x = {1, 2, 3, 4, 5}
disp(map('@(x) (iseven(x) and 2*x) or 0', x), '')
-- or
disp(map('@(x) qq(iseven(x), 2*x, 0)', x), '')
-- {0, 4, 0, 8, 0}

-- to pass a function to another function not defined in MathLua
a = {2, 5, 1, -3}
x = sort(a, ff('@(x, y) x > y')) -- or table.sort(a, function(x, y) return x > y end)
disp(x)
disp(x * 5 - 10)

The shortcut for defining a function here might not work if local objects are accessed. For example,

require('mathly')

clear()
axissquare()
do
  local a = 5
  plot(polarcurve(function(t) return cos(a*t) end, {0, 2*pi}))
end

Here, function(t) return cos(a*t) end can't be replaced with '@(t) cos(a*t)' because a is supposed to be a global variable, which is why the following code works. 

require('mathly')
clear()
axissquare()
a = 5
plot(polarcurve('@(t) cos(a*t)', {0, 2*pi}))

✓   The function, qq, allows more complicated expressions to be defined through this shortcut.

Named arguments

Functions for plotting graphs or providing plot with graphics objects allow "named" arguments, including plot3d, plotsphericalsurface, plotparametricsurface, plotparametriccurve3d, parametriccurve2d, polarcurve, contourplot, scatter, slopefield, vectorfield2d, hist, hist1, pareto, freqpolygon, histfreqpolygon, boxplot, pie, arc, circle, polygon, line, point, text, wedge.

The basic rule is that unnamed arguments go first and are in specific order, and all named arguments must be put in a single list. In the list, each item is named, and the order of items doesn't matter.

See also: function namedargs(data, opts).

require('mathly')

-- the following commands generate each the same graphics object
vectorfield2d('@(x, y) {-y, x}', {-5, 5}, nil, 3)             -- unnamed arguments

vectorfield2d('@(x, y) {-y, x}', {-5, 5}, nil, {scale=3})     -- unnamed and named arguments
vectorfield2d('@(x, y) {-y, x}', {xrange={-5, 5}, scale=3})
vectorfield2d('@(x, y) {-y, x}', {scale=3, xrange={-5, 5}})

vectorfield2d({f='@(x, y) {-y, x}', xrange={-5, 5}, scale=3}) -- named arguments
vectorfield2d({scale=3, xrange={-5, 5}, f='@(x, y) {-y, x}'})
vectorfield2d{scale=3, xrange={-5, 5}, f='@(x, y) {-y, x}'}

Note: Since plot is so basic and general a tool, it is designed to treat arguments differently. It can take two or more "named" arguments which can occur before an unnamed argument. For instance,

require('mathly')
clear()
plot({layout={width=600, height=400}}, sin, {xrange={0, 2*pi}})
