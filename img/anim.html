MathLua: animate, manipulate

•   animate(fstr, opts)

See also: manipulate, Gallery of Math Animations.

Animate a parametric curve or the graph of a single-variable function f(x) with controls. Each control is a single letter, a, b, ..., z, A, B, ..., or Z, except p, t, x, y, T, X, and Y. For example, a, h, and k are controls in f(x) = a (x - h)^2 + k for exploring the variation of the parabola as they change.

fstr must be a string for y = f(x) or a pair of strings for a parametric curve. The string(s) must be a function in the shortcut string format. fstr can also be nil, if all graphic elements are plotted through JavaScript and/or the enhancements field (e.g., animate_shooting_method_by_guesses.lua).

The opts is a table of tables, used to specify layout, the range of t, etc. You may include optional enhancements in it to improve the effect of an animation. An enhancement is actually a simple graphics object here, i.e., a line, a point, a text, or a parametric curve, of which the properties, color, size, width, whenever applicable, can be specified. If more attributes are needed, define them through field style in a string, such as style = "symbol: 'diamond', line: { color: 'rgb(0, 0, 0)', width: 2 }" for a point. You may search keywords like Plotly JavaScript line style, Plotly JavaScript point style, and Plotly JavaScript textfont style for more information.

  1. (X, Y) are the coordinates of the currently plotted point on the animated curve defined in fstr. If the curve is defined by parametric equations, T refers to the value of the parameter t for the currently plotted point; if it is defined like '@(x) ...', T assumes the same value of X (because y = f(x) can naturally be parametrized as {'@(t) t', '@(t) f(t)'} with x = t). They and each control as well can be used in enhancements, and expressions containing them must be in a string, such as '2*X - a * Y + k'. They are global variables accessible by JavaScript code.
  2. While a control is a single letter, its label can be a word or so, defined like in m = {0, 3, 1, label = 'Option'}, where m is a control.
  3. Each control is a global variable accessible to JavaScript code. In addition, the global variable mthlyTraces, an array of traces to be shown on the graph, and the global constants like mthlyxMin, mthlyxMax, mthlyxStep, mthlyyMin, mthlyyMax, mthlytMin, mthlytMax, mthlytStep, mthly<c>Min, mthly<c>Max, and mthly<c>Step, the lowest and largest values and the step size of x, y, t and each control <c>, respectively, on the graph, are all accessible to JavaScript code. Note: mthlyyStep is not defined.

    Users may use the following predefined global variables in JavaScript code for their own needs, including improving the performance of JavaScript code. They are mthlyGlobal and mthlyGlobal1 ~ mthlyGlobal6, each initialized to [], i.e., say, mthlyGlobal3.length == 0. See animate-taylor-series_sine.lua.

  4. All controls can be specified in opts.controls like 'ahk', 'a, h, k', 'a h, k', etc. If the field, controls, is not specified, they will be recognized automatically from the string expression of y = f(x) or parametric equations in fstr in the order they occur.
  5. With a control, field default defines the initial value of the control. If not provided, it defaults to start.

  6. The parameter of a parametric curve, specified in fstr or enhancements, must be t. The field fill may be specified to fill related regions (See fill = 'fa'|'ff'|'fn'|'fs').

  7. The range of a control and the parameter of a parametric curve is of the form { start, stop, step }. For the parametric curve defined in fstr, if the range of t is omitted, it defaults to the range of x, if the latter is specified, or {-5, 5, 0.1}.

    ✓   For a parametric curve defined in enhancements, if the range of t is omitted, it defaults to the range of t in fstr (when fstr = {'@(t) ...', '@(t) ...}) or x (when fstr = '@(x) ...'), so, the curve is dynamical, i.e., it is animated together with the curve defined by fstr; otherwise, the curve is static.

  8. For each graphics object defined in fstr or in enhancements, field style can specify more properties of the object allowed by Plotly. It is a string like style = "dash: 'dot'" and style = "dash: 'dot', color: 'red', width: 2" for a curve or a line. Here, dot can be dash, dashdot, longdash, longdashdot, etc.
  9. Field opts.resolution may be needed for smooth parametric curves. It defaults to 500. The larger, the smoother, but more computing power is needed. With each parametric curve in enhancements, field resolution can be defined separately, and its default and minimum value is 500.

  10. Show no title? Add option layout = { title = '' }.

  11. No square aspect ratio? Add option layout = { square = false }.

  12. Do not show axes? Add option layout = { xaxis = { visible = false }, yaxis = { visible = false } }.

  13. As with plot, xrange and yrange in table opts define the ranges of x and y displayed on a graph.

✓   Let animate start playing an animation

At a specific moment? Set the default value of the reserved control p, hooked to the Play slider, like p = { default = x } where x is between 0 (beginning, default) and 1 (end).

At a specific speed? Add option speed = n. It is equivalent to pressing the button Slower (Faster) |n| times if n is negative (positive).

See smiley_face.lua.

✓   Let animate work like manipulate.

Click the Pause button first. Then, click the Play slider and drag all the way to the end of the slider to show the entire graph if necessary. Now, manipulate the parameters. 

require('mathly')

fstr = '@(x) x^2'
opts = {
  xrange = {-6, 6}, yrange = {-2, 40},
  layout = {width = 500, height = 350, square = false}, -- square aspect ratio, square = true, by default
  enhancements = {{x = 'X', y = 'Y', color = 'red', size = 10, point = true}}
}
animate(fstr, opts)

JavaScript code can be added as follows for animations which involve more complicated computing. The enhancements may access variables and functions defined in the JavaScript code.

  1. Names of user-defined variables and functions can NOT be p, t, x, y, T, X, Y where p is reserved for 'play'.
  2. The title of a graph can be dynamically changed through the interface, displaytitle(), a user-defined JavaScript function that returns a string, the title.
  3. If needed, an extra message can be displayed through the interface, displaytext(), a user-defined JavaScript function that returns a string, the message.

    {x = '@(t) 1.5*cos(t)', y = '@(t) -0.5 + 1.5*sin(t)', t = {pi, 2*pi}},                      --
    {x = '@(t) t', y = '@(t) 3 * sin(t)', color = 'green'},                                     -- t's range is not given: sync with fstr. note: if fstr = '@(x) ...', t = x

✓   Note: With text in enhancements, if dynamical evaluation is needed, it must be defined like text = "...' + expr1 + '...' + expr2 + '...' [+ more terms] + '...", where ... can be any text, expr1, expr2, ..., are each a JavaScript expression to be evaluated dynamically. If an expression contains multiple terms, we may have to use parentheses to make them a single term, such as (I + 1).

•   manipulate(f, ...)

See also: animate, Gallery of Math Animations.

Manipulate a parametric curve or the graph of a single-variable function f(x) with controls.

Both manipulate and animate have the same usage. While manipulate displays a curve, animate shows how the curve is dynamically generated.

require('mathly')

-- Lissajous curves
jscode = [[
  function displaytext() { return "x(t) = a sin(mt), y(t) = b sin(nt)"; }
]]
opts = {
  t = {0, 2*pi, 0.01},
  a = {0.1, 5, 0.1, default = 2.5}, m = {1, 20, 1, default = 5},
  b = {0.1, 5, 0.1, default = 3.6}, n = {1, 20, 1, default = 9},
  xrange = {-5.1, 5.1},
  resolution = 2000,
  javascript = jscode,
  layout = {
    width = 640, height = 540, title = '<h3>Lissajous Curves</h3>',
    xaxis = { visible = false }, yaxis = { visible = false }
  }
}
manipulate({'@(t) a*sin(m * t)', '@(t) b*sin(n * t)'}, opts)
--



fstr = {'@(t) cos(t) + 1/m * cos(a*t) + 1/n * cos(b*t+3.1416/2)',
        '@(t) sin(t) + 1/m * sin(a*t) + 1/n * sin(b*t+3.1416/2)'}
opts = {
  t = {0, 2 * pi, 0.01},         ----- adjust options if needed
  m = {1, 20, 1, default = 2}, n = {1, 20, 1, default = 2},
  a = {-10, 10, 1, default = 8}, b = {-20, 20, 1, default = -13},
  xrange = {-4, 4},
  resolution = 2000,
  layout = {
    width = 500, height = 500, square = true,
    title = 'x(t) = cos t + 1/m cos(at) + 1/n cos(bt + π/2)
y(t) = sin t + 1/m sin(at) + 1/n sin(bt + π/2)',
    xaxis = { visible = false }, yaxis = { visible = false }
  }
}

JavaScript and enhancements are allowed as with animate.

require('mathly')

jcode = [[
  function displaytext() { // dynamically show the function
    let op1 = '-', op2 = '+', h1 = h, k1 = k, x = 'x', t = '', ax = ''
    if (h < 0) { op1 = '+'; h1 = -h; }
    if (k < 0) { op2 = '-'; k1 = -k; }
    if (h != 0) { x = '(x ' + op1 + ' ' + h1 + ')'; }
    if (k != 0) { t = op2 + ' ' + k1; }
    if (a != 0) {
      ax = '' + ((a == 1)? '' : ((a == -1)? '-' : a)) + x + '2 ';
    } else {
      t = k;
    }
    return 'y = ' + ax + t
  }
]]
fstr = '@(x) a * (x - h)^2 + k' -- a, h, and k are each a control here
opts = {
  a = {-3, 3, 0.02, default = 3}, h = {-10, 10, 0.5, default = 0}, k = {-90, 90, default = 0},
  xrange = {-10, 10}, yrange = {-100, 100},
  javascript = jcode,
  layout = {
    width = 600, height = 400, square = false,
    title = "y = a (x - h)2 + k"
  }
}
manipulate(fstr, opts)
