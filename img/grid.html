Plotly JavaScript Figure Reference: layout and grid

You can find the basic usage of the attribute, layout, in examples of this documentation. For more information about the option and more control of your figure, you may refer to the official website of Plotly Javascript Figure Reference at https://plotly.com/javascript/reference/layout/.

For simplicity and the small size of MathLua, we just cover a small subset of the features provided by Plotly JavaScript graphing library. However, it doesn't set limitations for you to experiment with various attributes supported by Plotly.

By the way, if you want more control over a graph/figure, you can always let MathLua plot it first and then start working on its output, the HTML file _tmp-mathly_plot-6_4.html.

Attributes gridaxes and gridaxisnames can specify axis labels of subplots.

require('mathly')

axissquare()
plot(
  sin, cos, '@(x) x', '@(x) x^2',
  {layout = {
     width = 800, height = 500, title = "Example",
     grid = {rows = 2, columns = 2, xranges = {{-pi, pi}, {-2*pi, pi}, {-5, 5}, {-20, 20}}},
     gridaxes = {
       xaxis  = {title = "x label 1"}, yaxis  = {title = "y label 1"},

       xaxis2 = {title = "x label 2"}, yaxis2 = {title = "y label 2"},

       yaxis3 = {title = "y label 3"},
       xaxis3 = {title = "x label 3", domain = {0, 0.3}, scaleanchor = 'y3', scaleratio = 1}, -- square aspect ratio

       xaxis4 = {title = "x label 4", domain = {0.4, 1}}, yaxis4 = {title = "y label 4"}
     },
     margin = {l = 58, r = 50, t = 40, b = 45, pad = 10},
     autosize = false
    }
  }
)
--

Here, the domain attribute is used to define the positioning and the size of a subplot within the overall figure area, specified in normalized coordinates from 0 to 1. By default, space is evenly assigned to each subplot. Adjusting the range of the attribute, we can position subplots as we want.

clear()
x = linspace(0, pi, 100)
y1 = x^2
y2 = sin(x)
y3 = x^2 * sin(x)
showlegend()

-- without 'domain', the arrangement of subplots is a 2x2 grid, with one subplot blank
plot(x, y1, {name='x2', style=':', color='cyan', symbol='circle-open', size=4},
     x, y2, {color='blue', name='sin x'},
     x, y3, {name = 'x2 sin x'},
     {layout = {
        width =600, height = 600,
        title='Example',
        grid = {rows = 2, columns = 2},
        gridaxes = {
          xaxis  = {title = "x label 1"}, yaxis  = {title = "y label 1"},
          xaxis2 = {title = "x label 2"}, yaxis2 = {title = "y label 2"},
          xaxis3 = {title = "x label 3"},
          yaxis3 = {title = "y label 3"}
        },
        margin = {l = 58, r = 50, t = 40, b = 45, pad = 10},
        autosize = false
      }})
--

✓   If the x and y ranges of subplots vary, the attributes xranges and yranges can be useful. They take the same format, e.g., layout.grid.xranges = {{start, stop, step}, {start, stop, step}, ....}, where xranges[i] is for the ith function/graph appearing in plot(...) from left to right, and step is optional, used to generate the x values of the ith subplot on [start, stop] if needed. If no such a range is needed, nil should be at the very position in the list. For example,

x = linspace(0, 10, 300)
axisnotsquare()
plot(sin, '-r', x, cos(x^2), {color='blue'}, exp, '@(x) exp(2*x)',
  {layout = {
      grid = {rows = 2, columns = 2,
              xranges = {{0, pi}, {0, 2*pi}, {0, 5},   {0, 7}},
              yranges = {{-1, 1}, {0, 1},    {0, 100}, {0, 1000000}}
             },
      autosize = false
    }
  }
)
--

plot(sin, '-r', x, cos(x^2), {color='blue'}, exp, '@(x) exp(2*x)',
