•   arc, circle, line, parametriccurve2d, point, polarcurve, polygon, scatter, wedge

arc(radius, center, angles, style) Return a graphics object for plot to plot an arc of a circle, where angles: {angle1, angle2} (default: {0, 2π}).
circle(radius, center, style) Return a graphics object for plot to plot a circle, where center: {x, y} (default: {0, 0}).
line(point1, point2, style) Return a graphics object for plot to plot a straight line, where point1 = {x1, y1} and point2 = {x2, y2}.
parametriccurve2d({x(t), y(t)}, trange, style, resolution, orientationq) Return a graphics object for plot to plot a parametric curve, where x(t) and y(t) are parametric functions, and range = {t1, t2} (default: {-5, 5}) indicating t changes from t1 to t2.
point(x, y, style) Return a graphics object for plot to plot a point, where (x, y) are the coordinates of the point. Note: point({x1, x2, ...}, {y1, y2, ...}, style) or point({{x1, y1}, {x2, y2}, ...}, style) is for plotting multiple points.
polarcurve(r(θ), θrange, style, resolution, orientationq) Return a graphics object for plot to plot a polar curve, where r(θ) is a polar function, and θrange = {θ1, θ2} (default: {0, 2*pi}) indicating θ changes from θ1 to θ2. If r is a number, plot a circle with radius r.
polygon(vertices, style) Return a graphics object for plot to plot a polygon, where vertices = {{x1, y1}, {x2, y2}, ..., {xn, yn}} specifies the coordinates of each vertex in order so that there is an edge connecting any two consecutive vertices. There is an edge connecting {x1, y1} and {xn, yn}.
scatter(x, y, style) Return a graphics object for plot to plot a scatter plot. It has similar usage like point.
text(x, y, txt, style) Return a text object for plot to write a text string txt at the point (x, y) on a graph.
wedge(radius, center, angles, style) Return a graphics object for plot to plot a wedge of a disk, where angles = {θ1, θ2} indicating θ changes from θ1 to θ2.

Note: Functions plotparametriccurve2d and plotpolarcurve are acturally, say, plot(polarcurve(...)).

✓   For most of these graphics objects, we may use these specifications in style to shade specific regions.

Other specification shortcuts, see plot.

✓   resolution - Functions, parametriccurve2d, plot3d, plotparametriccurve2d, plotparametriccurve3d, plotparametricsurface, plotsphericalsurface, and polarcurve, each take an argument, the minimum resolution (default: 100 for a surface, or 500 for a curve), for users to control the smoothness of a plotted curve or surface if needed. A larger value means better smoothness and requires more computing time.

✓   orientationq - Functions, parametriccurve2d, plotparametriccurve2d, plotparametriccurve3d, and polarcurve, each take also a last argument, orientationq (default: false). If it is true, a few dots of reducing sizes are plotted together with a curve to show the orientation of the parametric curve. The orientation is from large to small dots (➤).

✓   See also: Shortcut for defining an anonymous function.

•   plotpolarcurve(r, trange, style, resolution, orientationq)

Plot a single polar curve defined by r(θ). It is simply plot(plotpolarcurve(r, trange, style, resolution, orientationq)).

✓   To plot multiple (polar) curves on a single figure or a polar curve with more configurations, please use polarcurve together with plot.

✓   See also: Shortcut for defining a function for this function.

require 'mathly'
axissquare()
plotpolarcurve(1, {0, 2*pi}, 'rfs')
--

plotpolarcurve(function(t) return sin(cos(tan(t))) end, {0, 2*pi}, 'rfs')
--

plotpolarcurve('@(t) exp(cos(t)) - 2*cos(4*t) + sin(t/4)^3', {0, 10*pi})
--

To plot multiple polar curves in a single figure, use plot. See polarcurve. Below can be a different version of plotpolarcurve.

require('mathly')

function plotpolarcurve(r, trange, style, resolution, orientationq)
  if type(r) ~= 'table' then
    plot(polarcurve(r, trange, style, resolution, orientationq))
  else
    local cs = {}
    for i = 1, #r do
      cs[i] = polarcurve(table.unpack(r[i]))
    end
    if trange then cs[#cs + 1] = trange end
    plot(table.unpack(cs))
  end
end

axissquare()
plotpolarcurve('@(t) t', {0, 10*pi})
--

plotpolarcurve(
  {{'@(t) t', {0, 10*pi}},
   {'@(t) t^2', {0, 6*pi}},
   {'@(t) sqrt(t)', {0, 8*pi}},
   {'@(t) t^2*cos(t)', {0, 8*pi}}},
  {layout={width=640, height=600, grid={rows=2, columns=2}}})
--

•   plotparametriccurve2d({x(t), y(t)}, trange, style, resolution, orientationq)

Plot a single 2D curve defined by {x(t), y(t)}. It is simply plot(parametriccurve2d({x(t), y(t)}, trange, style, resolution, orientationq)).

resolution and orientationq? See parametriccurve2d and polarcurve.

✓   To plot multiple (parametric) curves on a single figure or a parametric curve with more configurations, please use parametriccurve2d together with plot.

✓   See also: Shortcut for defining a function for this function.

require('mathly')
axissquare()
plotparametriccurve2d({cos, sin}, {0, 6*pi}, "--rfs")
plotparametriccurve2d({'@(t) t*cos(t)', '@(t) t*sin(t)'}, {0, 8*pi})

To plot multiple parametric curves in a single figure, use plot. See polarcurve.
