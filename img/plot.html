MathLua: plot(...)

Plot the graph(s) of functions defined by data points, using specifications/options.

Some specifications:

  1. of a line, i.e., the graph of a function:

    width = 5

    style = '-' [solid, ':' (dot), or '--' (dash)]

    mode = 'lines+markers', 'lines', or 'markers'

  2. of a marker:

    size = 10

    symbol = 'circle'

    Some possible symbols are bowtie, circle, circle-open, circle-open-dot, cross, diamond, hexagram, hourglass, pentagon, square, square-open, star, triangle-left, triangle-right, triangle-up, triangle-down, x, etc.

  3. of a plot:

    layout = {width = 500, height = 400, grid = {rows = 2, columns = 2}, title = 'Demo'}

Shortcuts for specifications like '--ro':

shortcut   symbol
o   circle
*   star
x   cross
^   triangle-up
v   triangle-down
>   triagle-right
<   triagle-left

shortcut   color
r   red
b   blue
g   green
c   cyan
m   magenta
y   yellow
k   black
w   white

✓   Filling specific regions? See examples.

✓   See also: Shortcut for defining an anonymous function; Plotly JavaScript Figure Reference: layout and grid.

Examples:

require('mathly')

clear()
x = linspace(0, pi, 100)
y1 = sin(x)
y2 = cos(x)
y3 = x^2 * sin(x)

specs1 = {layout={width=600, height=600, grid={rows=2, columns=2}, title='Example'}}
specs2 = {color='blue', name='cos x', layout={width=500, height=500, grid={rows=4, columns=1}, title='Demo'}}
specs3 = {width=3, name='x2', style=':', color='cyan', symbol='circle-open', size=4}

plot(sin)
--

plot('@(x) x^2', {xrange={-6, 6}})
--

plot(sin, '-r',
     '@(x) x^2', {color='blue'},
     {xrange = {-0.5, 1}},
     {layout = {title = 'Demo', xaxis = {title = 'x'}, yaxis = {title = 'y'},
                margin = {l = 40, r = 40, t = 40, b = 40, pad = 40}}})
--

shownotlegend()
plot(x, y1, '--xr',
     x, y2, ':g',
     text(0.79, 0.71 - 0.08, 'A'),
     point(0.79, 0.71, {symbol='circle', size=10, color='blue'}))
--

plot(x, y1, x, y2, specs1, sin, '--r')
--

showlegend()
plot(x, y1, specs3,
     x, y2, specs2,
     sin, {name = 'sin x'},
     x, y3, {name = 'x2 sin x'},
     specs1) -- multiple layouts are merged into one with the last one overwriting others
--

axisnotsquare()
A = rand(125, 4) -- each column of A defines a function with x changing from 0 to # of rows
plot(A, specs1, {names={'f1', 'f2', 'f3', 'g'}})
--

plot(rand(100,5), {layout = {grid = {rows=3, columns=3}}}, rand(100,3))
--

✓   The options xrange and yrange of plot can be used to specify the ranges of x and y for all graphs on a single figure. They take the same format, e.g., xrange = {start, stop, step}, where step is optional, used to generate x values on [start, stop] if needed. For example,

require('mathly')
x = linspace(0, 10, 300)
axisnotsquare()
plot(x, x^4*sin(x), '-r', x, x*cos(x^2), '-b', exp, {xrange={0, 5}, yrange={-5,30}})
--

fs = table1('!@(x) cos(i * x) * sin(i - x)', {i = {1, 4}, controls = 'i'})
display(fs, 2)
plot({xrange = {-6, 6}}, table.unpack(fs))
--

plot({xrange = {-6, 6, 0.01}}, table.unpack(fs)) -- smoother
--

✓   We may use the following specifications to shade specific regions.

'fa' - Fill to the x-Axis
'ff' - Fill to to the previous Function
'fn' - No filling
'fs' - Fill to Self
require 'mathly'

axisnotsquare()
plot(sin, '-rfa')
--

x = linspace(-2.337, 0.779, 100)
X = linspace(-5, 5, 200)
plot(X, cos(X), X, sin(X), '-rff') -- shade regions between two curves
--

plot(x, cos(x), x, sin(x), '-rff', X, cos(X), X, sin(X))
--

f = ff('@(x) sqrt(1 - x^2)')
g = ff('@(x) 6 - (x - 2)^2')
k = ff('@(x) x')
a = fzero('@(x) f(x) - g(x)', 0)
b = fzero('@(x) f(x) - k(x)', 1)
c = fzero('@(x) g(x) - k(x)', 3)
axissquare()
xfg = linspace(a, b, 300)
xkg = linspace(b, c, 200)
plot(
  -- draw graphs first
  f, 'k', g, 'k', polarcurve(1, {0, 2*pi}, '-k'),
  {xrange = {-1.1, 4.5}, yrange = {-1.1, 6.1}},

  -- shade specific region(s)
  xfg, f(xfg), 'k', xfg, g(xfg), '-lkff', -- like partitioning a region into y-simple
  xkg, k(xkg), 'k', xkg, g(xkg), '-lkff'  -- subregions when evaluating a double integral
)
--
